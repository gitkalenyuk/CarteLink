♾️ Як абузити і отримати БЕЗКІНЕЧНУ квоту (Безліміт 24/7)

        

          Головна перевага CartelGate полягає в тому, що він перетворює обмежені безкоштовні квоти провайдерів на безперервний безлімітний потік для твого Claude Code / Cursor / Cline.
        

        

          

            
💎

            

              Чому Google Antigravity — це золота жила?
              Google надає кожному звичайному Google-акаунту безкоштовний доступ до топових моделей gemini-3.8-flash-high, gemini-3.8-pro-high та claude-sonnet-4-6 (Antigravity) без жодної платної підписки! Кожен акаунт має добові ліміти запитів (RPD) та ліміти за хвилину (RPM).
            

          

          

            
🎯

            

              Скільки акаунтів потрібно для щоденної роботи?
              
    
                
  • 3 – 5 безкоштовних Google-акаунтів: Цього достатньо для повноцінної щоденної роботи одного активного розробника (8-10 годин безперервного кодингу).
    • 
                
  • 10+ безкоштовних акаунтів: Практично невичерпний безліміт. Поки один акаунт тимчасово вичерпав хвилинну квоту або добовий ліміт, рушій перемикається на наступний, а попередній встигає повністю скинути кулдаун!
    • 
                
  • Pro / Google Workspace акаунти: Мають у рази вищі ліміти токенів і меншу чутливість до RPM, але навіть звичайні безкоштовні акаунти у зв’язці дають 100% результат.
    • 
              

            

          

          

            
⚡

            

              Секрет успіху: режим «Викачувати по черзі (Fill-First / Сушити всі акки)»:
              У вкладці «Моделі» увімкни Fill-First. Шлюз буде повністю застосовувати перший акаунт. Щойно Google повертає статус HTTP 429 (Resource Exhausted), CartelGate миттєво і прозоро для Claude Code перемикає наступний запит на другий акаунт. Твій кодинг ніколи не переривається помилками!
            

          

          

            
🛡️

            

              Чисті приватні вікна для додавання акаунтів:
              Кожен раз, коли ти натискаєш «Gemini-Antigravity — увійти» або іншу кнопку входу, CartelGate запускає Edge/Chrome з окремим тимчасовим профілем в інкогніто — без куків твого основного браузера. Тому можна авторизувати 10 різних Google-акаунтів один за одним без змішування сесій, і після успішного входу вікно закривається автоматично (профіль стирається). Якщо Edge/Chrome не знайдено, відкривається стандартний браузер — тоді вікно треба закрити вручну.

🌟 Що таке CartelGate?

        

          CartelGate — це локальний шлюз-проксі (AI Gateway) від YouTube Cartel, який збирає твої акаунти й ключі різних провайдерів (Google Antigravity, OpenAI Codex, Kimi, Claude, xAI, Meta + 70 OpenAI-сумісних API) в один «картель» — єдину точку доступу з ротацією та підміною моделей.
        

        

          Шлюз повністю емулює офіційні API Anthropic Messages (для Claude Code, Cursor, Claude Desktop) та OpenAI Chat Completions (для Cline, Roo Code, Continue, LangChain). Твої інструменти розробки працюють так, ніби вони підключені безпосередньо до офіційних API, а CartelGate прозоро розподіляє навантаження, підмінює моделі, знімає фейкові системні промпти та балансує квоти.
        

      


      

        

          
⚙️ Як це працює «під капотом»?

          
    
            
  • Вбудований рушій CLIProxyAPI: Весь код проксі-рушія скомпільовано in-process безпосередньо в бінарний файл програми. Жодних зовнішніх залежностей або неконтрольованих фонових процесів.
    • 
            
  • Єдиний порт і Gin Engine: Панель керування та AI-ендпоінти працюють на одному порту за спільним рушієм, використовуючи легке нативне вікно Windows WebView2.
    • 
            
  • Прозорий Request Rewriter: Запити від Claude Code аналізуються на льоту. Якщо Claude Code надсилає запит на claude-sonnet-5 або використовує внутрішній рівень Sonnet, шлюз миттєво підставляє реальну обрану тобою модель (наприклад, gemini-3.8-flash-high).
    • 
            
  • Очищення промптів (Uncloaking): Виправляє фейкові системні директиви Claude Code, коли сторонні моделі примусово представлялися як «Claude Fable 5». Моделі чесно звітують про свою справжню сутність.
    • 
          

        


        

          
🔄 Ротація акаунтів («Сушити всі акки»)

          

            Тобі не потрібно обирати окремий акаунт для кожної задачі! Усі підключені акаунти одного провайдера автоматично об'єднуються у спільний пул.
          

          
    
            
  • 
              ⚡ Викачувати по черзі (Fill-First / Сушити всі акки):
              Шлюз направляє 100% запитів на перший активний акаунт. Щойно провайдер повертає помилку вичерпання квоти HTTP 429 (Resource Exhausted), шлюз автоматично перемикається на наступний акаунт без переривання твоєї сесії кодингу.
            
    • 
            
  • 
              🔄 По черзі (Round-Robin):
              Запити рівномірно чергуються між усіма підключеними акаунтами провайдера по колу, забезпечуючи рівномірне споживання лімітів.

🚀 Покрокова інструкція швидкого старту (Claude Code)

        

          

            
1

            

              Підключи свої акаунти: Перейди на вкладку «Акаунти» та натисни кнопки входу (наприклад, Gemini-Antigravity, Codex, Kimi). Авторизуйся у вікні браузера, що відкриється. Можна додати 2, 5, 10 чи більше акаунтів.
            

          

          

            
2

            

              Обери стратегію ротації та моделі: У вкладці «Моделі» обери режим ротації (наприклад, Fill-First / Сушити всі акки) та признач моделі для рівнів Haiku, Sonnet, Opus або офіційних імен Claude. Натисни «Зберегти мапінг».
            

          

          

            
3

            

              Запусти сервер: Переконайся, що у вкладці «Сервер» горить зелений індикатор «Працює». Якщо ні — натисни кнопку «▶ Запустити».
            

          

          

            
4

            

              Скопіюй змінні у свій термінал: Скопіюй сніпет зі сторінки «Сервер» (кнопка «Копіювати») та виконай його у терміналі:
              
export ANTHROPIC_BASE_URL="http://127.0.0.1:8317"
export ANTHROPIC_AUTH_TOKEN="<твій_ключ>"
export ANTHROPIC_MODEL="gemini-3.8-flash-high"

            

          

          

            
5

            

              Працюй у Claude Code: Запусти команду claude у терміналі. Тепер Claude Code працює через CartelGate, використовуючи потужність твоїх підключених моделей з автоматичною ротацією та захистом від лімітів!
            

          

        

      


      

        
📖 Огляд розділів CartelGate

        

          

            
◉ Сервер

            
Головний пульт: статус шлюзу, адреси ендпоінтів для клієнтів, генерація API-ключів, налаштування мережевого порту та готовий сніпет підключення для терміналу.

            
≡ Провайдери

            
Понад 70 пресетів OpenAI-сумісних API (OpenRouter, Groq, DeepSeek, Ollama…) зі своїми ключами, редагування після додавання, підтягування списку моделей, рідні ключі Claude/Gemini/Codex.

            
▤ Моделі

            
Керування логікою підміни: вибір стратегії ротації акаунтів (Round-Robin або Fill-First), мапінг рівнів Haiku/Sonnet/Opus та індивідуальна підміна будь-якої офіційної моделі Claude.

          

          

            
◆ Акаунти

            
Управління підключеними OAuth-акаунтами: додавання нових акаунтів через браузер, перевірка статусу квот, переавторизація, видалення акаунтів та кнопка негайного скидання 429-лімітів.

            
▦ Статистика

            
Аналітика реального часу: загальні лічильники токенів (Prompt, Completion, Reasoning, Cache), відсоток успішності, живий статус квот кожного акаунта та черга останніх запитів (Live Usage Queue).

            
⚙ Налаштування

            
Мережева конфігурація (хост, порт), керування вимогами авторизаційного ключа та редагування розширеного конфігураційного YAML-файлу для досвідчених користувачів.
